# RFM Customer Segmentation Analysis Using Python

## Project Overview
This project uses Recency, Frequency, and Monetary (RFM) analysis to segment customers based on their purchasing behavior.

## Tools Used
- Python
- Pandas
- Plotly
- Jupyter Notebook

# Project Objectives
- Calculate RFM metrics for each customer.
- Assign RFM scores.
- Identify customer segments, including Champions and Potential Loyalists.
- Visualize customer segment distributions and purchasing patterns.
